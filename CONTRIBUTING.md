# Contributing to Frame OS

Thank you for your interest in Frame OS. These guidelines explain how to propose changes and discuss the project.

## Current project stage

Frame OS is in its planning and foundation stage. The initial product focus is Frame OS TV for Android TV.

Before proposing implementation changes, check the existing documentation and open discussions so work does not duplicate or conflict with current plans.

## Ways to contribute

Depending on the current project needs, useful contributions may include:

- Reporting reproducible bugs once software is available.
- Suggesting improvements to documented requirements.
- Identifying Android TV platform constraints.
- Reviewing documentation for clarity and accuracy.
- Proposing technical approaches with supporting reasoning.

## Before submitting a change

1. Check existing files, issues and pull requests.
2. Keep proposals focused and explain the problem they solve.
3. Include relevant device, platform or version details when reporting a technical issue.
4. Do not include passwords, access tokens, private user data or other secrets.
5. Check that any third-party code or assets may legally be used and include required attribution and license information.

## Pull requests

When pull requests are enabled for contributions:

- Use a clear, descriptive title.
- Explain what changed and why.
- Link related issues where applicable.
- Keep changes limited to the stated purpose.
- Update relevant documentation when behaviour or project decisions change.

## Project decisions

Technical choices and changes to product scope are subject to review by the project maintainer, AGP. A suggestion or pull request does not mean a feature or approach has been accepted.

## Code and licensing

The repository is public, but public visibility does not grant permission to reuse proprietary project code. No general contribution license or open-source license is granted by this document. Do not submit material unless you have the right to contribute it. Any accepted contribution must be handled consistently with the project's applicable rights and terms.

Third-party components remain subject to their own licenses.
