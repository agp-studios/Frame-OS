# Frame OS Roadmap

This roadmap describes the intended order of work. It is a planning document, not a promise of release dates. Tasks may change as research and testing reveal new requirements.

## Phase 1 — Project foundation

- [x] Create the public GitHub repository.
- [x] Establish the initial repository structure.
- [ ] Complete project vision and product documentation.
- [ ] Define contribution and project-management practices.
- [ ] Research Android TV development requirements.
- [ ] Record initial technical decisions and open questions.

## Phase 2 — Frame OS TV (Android TV)

Android TV is the only target platform for the initial Frame OS TV project.

- [ ] Define product requirements and core use cases.
- [ ] Evaluate the available Android TV development approaches.
- [ ] Decide the technical stack and project architecture.
- [ ] Create interface concepts and navigation flows.
- [ ] Plan remote-control and accessibility behaviour.
- [ ] Build a small technical prototype.
- [ ] Test on suitable Android TV devices or emulators.
- [ ] Evaluate performance, stability and compatibility.
- [ ] Document release, update and support requirements.

## Phase 3 — Frame OS TV development

This phase begins after the platform research, architecture and prototype have been reviewed.

- [ ] Implement the agreed core experience.
- [ ] Add features approved in the product requirements.
- [ ] Add automated and manual testing where appropriate.
- [ ] Resolve usability, performance and compatibility issues.
- [ ] Prepare release documentation.

## Phase 4 — Ecosystem expansion

Additional Frame software products may be considered after the initial TV work has a clear foundation. Their scope and priority will be decided separately.

## Current status

**Planning and repository foundation.** No production implementation or release date is being claimed at this stage.
