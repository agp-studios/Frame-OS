# Frame OS — Vision

## What is Frame OS?

Frame OS is a software ecosystem created by **AGP**. Its goal is to bring a consistent approach to software experiences, products and services developed under the Frame identity.

Frame OS is a working project name. Product names, features and technical decisions may evolve as research and development progress.

## Purpose

The project aims to:

- Create useful, modern and accessible software experiences.
- Keep product design and interaction patterns coherent across the ecosystem.
- Build with reliability, performance, privacy and maintainability in mind.
- Develop in stages, validating each product before expanding the ecosystem.

## First development focus: Frame OS TV

The first product focus is **Frame OS TV for Android TV**.

The initial work will concentrate on understanding the Android TV platform, defining the product scope, planning a television-friendly interface and evaluating technical requirements.

Android TV is the only confirmed target for this initial TV project. Other television platforms are outside the current scope unless AGP changes this decision later.

## Long-term direction

The wider Frame Ecosystem may grow to include additional software products and connected experiences. Those products will be planned and documented separately rather than assumed to be part of the first TV release.

## Project principles

1. **User-focused:** design for real use cases and clear interactions.
2. **Platform-aware:** respect the capabilities and requirements of each target platform.
3. **Consistent:** maintain a recognisable Frame experience.
4. **Reliable:** prioritise stability, testing and maintainable implementation.
5. **Responsible:** consider privacy, security, accessibility and third-party licenses.
6. **Incremental:** research, prototype, test and improve in manageable stages.

## Creator

Frame OS is created and maintained under the **AGP** identity.
